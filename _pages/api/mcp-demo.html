This page calls two tools of the Volunteering Data MCP server straight from your browser: activity_search and activity_by_location. Each search sends one JSON-RPC tools/call request to https://api.volunteeringdata.io/mcp; open "MCP exchange" below the results to see it.

Search by keyword

Uses activity_search. Lucene syntax works, e.g. garden* or dog AND walking.

Search near a location

Uses activity_by_location. Click the map to choose a point. The distance is limited to 5 km to keep responses small.
